# Nafiul Haque Nafee — Portfolio

A dependency-free, responsive personal portfolio designed for AI/ML, data science, analytics and product-technology opportunities.

## What is included

- Interactive hero with animated role text and background network
- Dark/light theme switcher
- Scroll progress indicator
- Accessibility-aware reveal animations and reduced-motion support
- Bento-style About section
- Dedicated thesis/research case study and poster preview
- Filterable project grid
- Interactive project detail modals
- Animated achievement counters
- GCI / BRAC University journey timeline
- Skills marquee and toolkit section
- Contact/copy-email controls
- Keyboard quick navigation: **Ctrl/Cmd + K**
- Included résumé PDF and thesis poster asset
- No external JavaScript or CSS dependencies

## Preview locally

From this folder:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy

### GitHub Pages
1. Create a repository, e.g. `portfolio`.
2. Upload these files to the repository root.
3. In **Settings → Pages**, deploy from the main branch/root.

### Vercel
1. Push this folder to GitHub.
2. Import the repository at Vercel.
3. Framework preset: **Other** / static site.
4. No build command is required.

### Netlify
Drag the folder into Netlify Drop or connect the GitHub repository. No build command is required.

## Before publishing

- Confirm every project link you want to expose publicly.
- Add a professional photo only if you want one; the current design intentionally uses a monogram instead.
- If the thesis repository becomes public, add its GitHub URL to the Research section.
- Do not add private datasets, API keys, credentials, restricted model weights, or unpublished confidential material.
- The camera-based fitness/game features are presented as prototypes where device validation is incomplete.
